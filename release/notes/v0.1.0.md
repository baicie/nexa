# Nexa UI v0.1.0 Technical Preview

This Technical Preview provides the first end-to-end Nexa UI desktop SDK train
and the signed Nexa Notes reference application for macOS arm64 and Windows
x64.

## Included

- Minimal TSX application runtime with lifecycle, scheduling, structured errors,
  focus, text editing, IME composition, semantics, and native rendering.
- Typed filesystem, dialog, and clipboard APIs with manifest permissions and
  cancellable task semantics.
- `@nexa/cli` create, doctor, build, and package workflows plus the nine-package
  `technical-preview` npm train.
- Signed Nexa Notes archives, checksums, CycloneDX SBOM, SLSA provenance,
  signing custody, and an exact release manifest.
- Solid as the sole Tier-1 framework adapter for this preview.

## Known Limitations

- Public desktop artifacts target macOS arm64 and Windows x64. Linux is not a
  release target for this preview.
- The runtime is single-window and uses the Skia CPU renderer. GPU rendering,
  multi-window navigation, menus, tray integration, and notifications remain
  post-preview work.
- Vue, React, and Svelte integrations remain compatibility candidates and are
  not part of the public package train.
- Public APIs and the Host ABI may change before a stable release; use the
  compatibility matrix and migration notes when upgrading.
