# Changelog

All notable changes to the Nexa UI Technical Preview are documented here.

## 0.1.0 - Unreleased

### Added

- Native Notes MVP reference application and typed FS/Dialog/Clipboard tasks.
- Minimal TSX UI runtime with text, IME, semantics, lifecycle, and packaging
  contracts.
- npm-first release boundary and reproducible version rehearsal scaffolding.
- Fail-closed schema-v5 MVP evidence with seven producer-bound quality/platform
  gates and native FS/real-picker runtime proof custody.
- Final-only Technical Preview publication contract for the exact seven-asset
  GitHub prerelease, provenance attestation, npm-channel convergence, and an
  immutable publication record.

### Known limitations

- Windows UI Automation and macOS/Windows real-picker hosted evidence are still
  required before the Desktop Notes MVP gate can close.
- The Node 22 hosted baseline, security gates, active performance baselines,
  registry clean-user proof, signing owners/credentials, dual-platform signed
  staging, rehearsal, and protected publication have not run successfully.
- No npm Technical Preview train or GitHub Release has been published from this
  candidate.
